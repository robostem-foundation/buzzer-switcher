First release of FieldCam Buzzer Switcher for Windows 10/11 (x64).

- Switch OBS scenes in a set order after a VEX IQ match ends.
- Require 45–70 seconds between start and end buzzers by default. This filters out quick start-and-stop attempts.
- Set the delay and detection threshold. Hover over an info icon for help. Use Listen Only to check the buzzers without switching scenes.
- Keep one OBS WebSocket connection open between switches.

Download `FieldCam-Buzzer-Switcher-v0.1-windows-x64.zip`, extract it, and follow `START HERE.txt`. Test with a full off-air practice match before arming at an event.
